# RepoMedic Architecture & Technical Design

## 1. System Overview

RepoMedic is an AI-assisted repository maintenance workbench engineered for open-source maintainers facing legacy dependency rot, breaking library shifts, and unverified migration debt. It bridges static dependency analysis, AST import mapping, local model reasoning, and safe sandbox execution into a single, reproducible pipeline.

---

## 2. Shared Data Contract

RepoMedic enforces a strict status vocabulary across all findings, recommendations, and execution attempts to eliminate ambiguity:

| Status | Definition |
|---|---|
| `observed` | Verifiable fact directly extracted from manifests, AST nodes, or environment |
| `inferred` | Static-analysis conclusion drawn by cross-referencing manifests against AST usage |
| `recommended` | Proposal generated by Hermes Agent or local model rules |
| `verified` | Executed in an isolated sandbox with exit code 0 |
| `failed` | Executed in an isolated sandbox with non-zero exit code or timeout |
| `blocked` | Execution prevented due to missing prerequisite or tool |
| `not_run` | Planned check that has not yet been executed |

All models inherit from `pydantic.BaseModel` in `repomedic/models.py` and produce standard JSON-schema-compliant structures.

## 3. Core Modules & Responsibilities

### `repomedic.safety`
- **Path Traversal Shield**: `validate_safe_path()` resolves target paths against the repository root and rejects any directory traversal escapes (`..`, symlinks).
- **Isolated Sandbox**: `IsolatedSandbox` creates a temporary, copy-on-write clone of the repository for verification experiments. The target repository is never mutated.

### `repomedic.scanner`
- **Manifest Ledger**: Parses `pyproject.toml`, `requirements.txt`, and `requirements-dev.txt`, preserving exact line-number provenance and raw requirement strings.
- **AST Import Parser**: Uses Python's built-in `ast` module to walk source files and test suites. Records top-level modules, imported symbols, line numbers, and conditional `try/except` guard status.
- **Cryptographic Fingerprint**: Hashes all manifests and source files using SHA-256 for audit immutability.

### `repomedic.analyzer`
- **Dependency Ghost Detector**: Cross-references declared manifest packages against AST imports. Flags packages with 0 observed imports (`six`, `idna`, `nose`).
- **Migration Tripwires**: Flags unmaintained packages and suggests modern replacements:
  - `toml` -> `tomllib` (Python 3.11+ standard library)
  - `appdirs` -> `platformdirs` (modern drop-in replacement)
  - `nose` -> `pytest` (removal of unmaintained test runner)
  - `pkg_resources` -> `importlib.resources` (deprecated setuptools API)
  - `pydantic` -> V1 `@validator` and `class Config` incompatibilities under Pydantic V2
- **Manifest Divergence**: Detects contradictory version pins across multiple manifests (e.g., `pydantic>=2` in `pyproject.toml` vs `pydantic==1.10.13` in `requirements.txt`).
- **Private API Usage**: Detects imports of internal private functions (e.g., `requests.utils._parse_content_type_header`).

### `repomedic.impact`
- **Change Blast-Radius Map**: Maps declared dependencies to direct importing source modules and transitively affected test suites.
- Assesses change risk as `LOW`, `MEDIUM`, or `HIGH`.

### `repomedic.hermes_adapter`
- Connects to Hermes Agent CLI (`hermes`) or local OpenAI-compatible endpoints (`REPOMEDIC_LOCAL_MODEL_URL`).
- Falls back gracefully to deterministic rule-based recommendations if no local inference runtime is active. Never invents unsupported CLI flags or hallucinates fake executions.

### `repomedic.verifier`
- Executes test commands inside `IsolatedSandbox` environments.
- Captures exact command arguments, execution duration in milliseconds, exit codes, and stdout/stderr streams.
- Records verification status as `VERIFIED`, `FAILED`, or `BLOCKED`.

### `repomedic.capsule`
- Compiles the final **Dependency Exit Capsule**.
- Computes a composite SHA-256 fingerprint from all manifest and source file hashes.
- Exports both machine-readable `capsule.json` and comprehensive human-readable `capsule.md`.
- Maintains a ledger of **Verification Debt** documenting unverified recommendations.
